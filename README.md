## Жоба туралы
Пайдаланушы өз параметрлерін (жасы, табысы, несие сомасы, мерзімі және т.б.) енгізеді. ML моделі несиенің қайтарылмау ықтималдығын есептеп, тәуекел деңгейін (төмен / орташа / жоғары) және оған әсер еткен негізгі факторларды көрсетеді. Сайтта несие калькуляторы мен қаржылық сауаттылық бөлімі де бар.

## Орнату командасы
Next.js жобасы мына командамен жасалды:

```bash
npx create-next-app@latest . --js
```
**Команда не істейді:**
- `npx` — Next.js жасаушысын (`create-next-app`) орнатпай-ақ, бір реттік іске қосады.
- `create-next-app@latest` — Next.js-тің ең соңғы нұсқасымен дайын жоба шаблонын жасайды.
- `.` (нүкте) — жобаны жаңа папка ашпай, қазіргі папканың (репозиторийдің) ішіне орнатады.
- `--js` — жобаны TypeScript емес, JavaScript-пен жасайды.

Нәтижесінде қажетті пакеттер (`next`, `react`, `react-dom`) орнатылады, `package.json`, баптау файлдары мен бастапқы бет жасалады, және `npm run dev`, `npm run build`, `npm start` командалары дайын болады.

## Жобаны іске қосу
Репозиторийді көшіріп алғаннан кейін:

```bash
git clone https://github.com/[АТЫҢЫЗ]/[РЕПОЗИТОРИЙ].git
cd [РЕПОЗИТОРИЙ]
npm install
npm run dev
```

Сайт `http://localhost:3000` мекенжайында ашылады. `npm install` қажет, себебі `node_modules` папкасы GitHub-қа жүктелмейді.

| Команда | Не істейді |
|---------|-----------|
| `npm run dev` | Әзірлеу серверін іске қосады |
| `npm run build` | Жобаны өндіріске дайындайды |
| `npm start` | Дайындалған жобаны іске қосады |
| `npm run lint` | Кодтың стилін тексереді |

## Жоба құрылымы
Төмендегі құрылым жоспар бойынша берілген. Орнатқаннан кейін өз папкаңызбен салыстырып тексеріңіз.

```
├── src/app/
│   ├── layout.js        # барлық беттерге ортақ шаблон
│   ├── page.js          # басты бет
│   ├── predict/         # тәуекелді болжау беті
│   ├── calculator/      # несие калькуляторы
│   ├── learn/           # қаржылық сауаттылық
│   └── model/           # модель туралы бет
├── public/
│   └── model/           # модель параметрлері (JSON)
├── ml/
│   ├── notebook.ipynb   # EDA, оқыту, бағалау
│   └── data/            # датасет
├── package.json         # пакеттер және командалар
├── next.config.mjs      # Next.js баптаулары
├── jsconfig.json        # JavaScript баптаулары
└── README.md
```

- `src/app/` — беттер мен layout (Next.js App Router).
- `public/` — статикалық файлдар (суреттер, модель JSON).
- `ml/` — машиналық оқыту бөлімі (Python, Jupyter Notebook).
- `package.json` — тәуелділіктер тізімі және командалар.

## Техникалық тапсырма (ТЗ)

### 1. Жоба атауы
**Менеджер** — несие тәуекелін ML арқылы бағалайтын және қаржылық сауаттылыққа үйрететін веб-платформа.

### 2. Өзектілігі
Көптеген адам несие алғанда өз мүмкіндігін дұрыс бағаламайды: төлем көлемін, пайыздық мөлшерлемені және қарыз жүктемесін ескермейді. Нәтижесінде төлем мерзімі өтіп кетіп, қарызға батады. Жоба пайдаланушыға несие алмас бұрын тәуекелді көруге және түсінікті түсіндірме алуға көмектеседі.

### 3. Мақсаты
1. Несие беру тәуекелін болжайтын ML моделін жасау (классификация).
2. Модельді Next.js сайтына қосып, түсінікті нәтиже көрсету.
3. Қаржылық сауаттылық бойынша оқу материалдары мен калькулятор ұсыну.

### 4. Мақсатты аудитория
Студенттер, жас мамандар, несие алуды жоспарлап жүрген тұрғындар.

### 5. Функционалдық талаптар

**5.1. Тәуекелді болжау беті**
- Пайдаланушы мына параметрлерді енгізеді (нақты тізім таңдалған датасетке қарай нақтыланады): жасы, жылдық табысы, жұмыс өтілі, үй-жай иелігі күйі, несие сомасы және мақсаты, пайыздық мөлшерлеме, мерзімі, несие тарихының ұзақтығы, бұрын мерзімін өткізген-өткізбегені.
- Форма деректерді тексереді (бос өріс, теріс сан, шектен тыс мән).
- Нәтиже: несиенің қайтарылмау ықтималдығы (%) және деңгей: төмен / орташа / жоғары тәуекел.

**5.2. Нәтиженің түсіндірмесі**
- Тәуекелге ең көп әсер еткен 3–5 фактор көрсетіледі.
- Тәуекелді азайту бойынша қысқа кеңестер беріледі.

**5.3. Несие калькуляторы**
- Сома, мерзім және пайыз бойынша айлық төлемді және жалпы артық төлемді есептейді (аннуитеттік формула).
- Төлем кестесін көрсетеді.

**5.4. Қаржылық сауаттылық бөлімі**
- Қысқа мақалалар: несие, пайыз, жылдық тиімді мөлшерлеме, кредиттік тарих, қарыз жүктемесі.
- "Несие алар алдында тексеретін сұрақтар" тізімі және FAQ.

**5.5. Модель туралы бет**
- Қолданылған датасет және жазбалар саны.
- Салыстырылған алгоритмдер.
- Метрикалар кестесі және confusion matrix.
- Модельдің шектеулері.

**5.6. Қосымша (уақыт болса)**
- Табыс пен шығысты бақылайтын қарапайым бюджет менеджері (деректер браузердің localStorage-інде сақталады).
- Қараңғы / жарық тема.
- Қазақша және орысша тіл ауыстыру.
- Екі сценарийді салыстыру.
