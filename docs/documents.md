# Құжаттар кітапханасы

«Құжаттар» қойындысы жүйеге кірген пайдаланушының сақталған құжаттарын көрсетеді.
Іздеу атау бойынша орындалады. Дереккөз (редактор / жүктелген файл) және сақталған
нұсқалар саны бойынша сүзуге, атауы немесе жаңартылған күні бойынша сұрыптауға болады.

- «Жаңа құжат» редакторда бөлек құжат ашады. Алғашқы сақтау — v1.
- Сақталған құжатты қайта ашып сақтау оның жаңа нұсқасын жасайды.
- «Нұсқалар» панелінде әр нұсқаның мәтінін қарап, жүктеп алуға болады.
- Ескі нұсқаны редакторда ашу тарихты өзгертпейді; сақтау жаңа нұсқа қосады.
- Бірдей атаулы файлдар бөлек құжаттар болып сақталады.
- «Нұсқалар» панеліндегі «Құжатты жою» құжат пен оның нұсқаларын жояды.
- Файл жүктеу мәтіндік пішімдерді қолдайды: TXT, MD, CSV, TSV, JSON, XML, HTML, LOG.
  Шектеу: 2 МБ файл және 200 000 таңба. PDF/DOCX сияқты бинарлық пішімдерге
  мәтін шығару осы жобада әлі қосылмаған.

Деректер бұрынғы `.data/agent.json` серверлік қоймасында сақталады. Бұрын сақталған
соңғы мәтін кітапханаға көшіріледі; бұрынғы жоғалған редакциялар қалпына келтірілмейді.
Күні белгісіз ескі құжаттар осылай белгіленеді. Бұл жергілікті JSON қоймасы бір Node
серверіне арналған; бірнеше сервермен іске қосу үшін ортақ транзакциялық дерекқор қажет.

## API

Барлық эндпоинттер `kt_session` cookie арқылы авторизацияны талап етеді.
Басқа пайдаланушының құжатына сұрау 404 қайтарады.

| Әдіс | Жол | Нәтиже |
| --- | --- | --- |
| GET | `/api/documents` | Жеке құжаттар тізімі, мәтінсіз метадеректер |
| GET | `/api/documents/:id` | Құжат және барлық сақталған нұсқалар |
| GET | `/api/documents/me` | Соңғы сақталған құжат, редакторды қалпына келтіру |
| DELETE | `/api/documents/:id` | Жеке құжат пен оның нұсқаларын жою |
| POST | `/api/documents` | `{title, text, source?}` — жаңа құжат |
| POST | `/api/documents` | `{documentId, baseVersion, title, text}` — жаңа нұсқа |

Ескірген `baseVersion` 409 қайтарады; редактордағы мәтін сақталады.
API жауаптары `private, no-store` тақырыбымен беріледі.

## Тексеру

```sh
npm ci
npm run lint
npm run build
npm run test:documents
```

Интеграциялық тесттер бөлек уақытша қойма мен бос порттағы production серверін
қолданады. Жұмыс деректерін өзгертпейді. `KT_AGENT_DATA_DIR` арқылы сервердің
қойма каталогын бөлек баптауға болады.

## Тіл және іздеу

Жоғарғы мәзірдегі тіл таңдауы қазақша, орысша және ағылшынша интерфейсті
ауыстырады. Таңдау браузерде сақталады және ашық қойындылар арасында жаңарады.
Құжаттар мен үлгілердің пайдаланушы енгізген мазмұны аударылмайды.

«Үлгілер» іздеуі атауды, сипаттаманы және қолжетімді мәтінді қамтиды.
«Тарих» іздеуі атауды, әрекет түрін және күнін қамтиды. Іздеу әріп регистрі
мен артық бос орындарға тәуелсіз; бірнеше сөздің барлығы сәйкес келуі керек.
Іздеу нәтижесінің саны көрсетіледі, сұрауды бір батырмамен тазалауға болады.
Тіл мен іздеу логикасын тексеру: `npm run test:ui`.
